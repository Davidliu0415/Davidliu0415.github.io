# Zhuo Liu — Interactive Portfolio

An English personal portfolio built as a living route between Dandong, Kuala Lumpur, and Nanjing.

## Public site

GitHub Pages serves the dependency-free version from the docs directory. It includes:

- An interactive OpenStreetMap / Leaflet route map with three clickable coordinates.
- English profile copy covering AI, systems, and quantitative research.
- Links to Face Sketches AI, AI Interview Agent, and Fin Research Lab.

## Development source

The root contains the Sites project source. The docs edition is intentionally self-contained so GitHub Pages can serve it without a build step or secrets.
